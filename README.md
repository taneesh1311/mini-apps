# Mini Apps

Little web apps that live in your Windows taskbar.

**To install:** download `Mini-Apps-Setup-….exe` from the [latest release](https://github.com/taneesh1311/mini-apps/releases/latest) and run it.
Windows may say it protected your PC: click **More info → Run anyway**.

`library/catalog.json` is the app list every install checks for new apps and updates.
